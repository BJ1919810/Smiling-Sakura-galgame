## 二、目录与工具地图

### 2.1 关键路径

| 路径 | 说明 |
|---|---|
| `笑樱_galgame台本.md` | ★ 唯一作者源 |
| `tools/compiler/` | 编译器：`parser.ts`（含 `starToFx()` 白名单）／`manifest.ts`／`rhythm.ts`／`play.ts` |

| `src/generated/*.json` | `script.json` / `assets.manifest.json` / `pose-split.json` / `rhythm-report.json` —— **⛔ 不要手改** |
| `public/assets/` | 运行时素材：`bg/` `cg/` `char/` `audio/bgm/` `audio/se/` |
| `素材基准/` | 原始素材与生产脚本（`立绘/` `背景/` `_工具/` `_参考/`） |

| `.workbuddy/backup/` | **删改前的备份**（台本快照、已删文档，**勿删**） |
| `node_modules/` · `dist/` · `src-tauri/target/` | 不进版本库 |

### 2.2 工具一览

| 工具 | 干什么 | 何时用 |
|---|---|---|
| `tools/compiler/index.ts` | 台本 → `script.json` ＋ 编译报告（幂等） | **每次改完台本** |
| `tools/compiler/manifest.ts` | 抽资源 key → `assets.manifest.json`（★ compile 不带它） | 改了资源行（BG/BGM/SE/CG） |
| `tools/build-exe.mjs` | **一键出桌面 exe** | 出包 |
| `tools/build-apk.ps1` | 出 Android APK（**必须从纯 ASCII 路径发起**） | 出包 |
| `tools/exe_probe.py` | exe 探针（资源路径表／时序链／体积） | 出包后验 |
| `tools/split-beats.py` | 长台词 → 多屏（分屏规则，幂等） | 拆屏 |
| `tools/transcribe-implicit-fx.py` | 把隐藏演出转录成显式 `※` 行（幂等） | 拆除隐藏行为 |
| `tools/polish-ch1.py` | 第 1 章语言精修的执行记录（样板） | 全篇推广时参照 |
| `tools/deploy-sprites.py` | 立绘 → `public/assets/char/`（只裁不缩，输出 `meta.json`） | 立绘交付后 |
| `tools/deploy-bgm.py` | BGM wav → `public/assets/audio/bgm/<manifest 编号>.ogg`（幂等） | 音频交付后 |
| `素材基准/_工具/mask_compose.py` 等 | 立绘透明化管线（黑白蒙版法） | 抠图 |

## 三、命令速查

```bash
# ── 编译与校验（★ 改了台本必跑）───────────────────
node --experimental-strip-types tools/compiler/index.ts   # 等价 npm run compile
#   → 必须看：error 0 / warning 0；章节 8 / 场景 59 / 选项 9 / 窗口 9 未变
npm run manifest       # ★ compile 不带它；改了资源行要单独跑
npm run typecheck      # tsc --noEmit
npm test               # 引擎单测（含验收用例 T1–T5）
npm run play           # 终端跑通全剧本（自动选 A，无渲染）
npm run rhythm         # 节奏报告（留白拍审计，阈值 12）
npm run posesplit      # 立绘姿态三轴分解
npm run diag:frame     # 画面适配自检（多比例视口）
npm run diag:hop       # 雀跃演出自检

# ── 跑起来（看完记得关端口）───────────────────────
npm run dev            # 开发服务器（Vite + React + PixiJS 舞台）
npm run shot           # Playwright 截图（复用系统 Edge，不下载 Chromium）

# ── 出包 ──────────────────────────────────────────
node tools/build-exe.mjs              # ★ 桌面 exe（bash 版会被沙箱拦）
powershell tools/build-apk.ps1        # Android（★ 必须从纯 ASCII 路径发起）

# ── 素材部署 ──────────────────────────────────────
python tools/deploy-sprites.py        # 立绘 → public/assets/char/
python tools/deploy-bgm.py            # BGM wav → public/assets/audio/bgm/<编号>.ogg

# ── 立绘透明化（黑白蒙版法，唯一管线）──────────────
python 素材基准/_工具/mask_compose.py <颜色层.png> <蒙版层.png> <输出.png>
python 素材基准/_工具/edge_clean.py <上一步.png> <输出.png>     # 清边（必做，blur 保持 0）
python 素材基准/_工具/matting_check.py <输出.png>               # 被裁/水印/alpha 分档
python 素材基准/_工具/mat_preview.py preview <输出.png>         # 棋盘格预览（必看）
```

### ⚠️ 本机环境保命规则（改任何命令前先看）

| 坑 | 对策 |
|---|---|
| **Bash 会丢 coreutils**（`ls/cp/find/grep` 全 command not found） | 每条命令前缀 `export PATH="$PATH:/c/Users/zbj/.workbuddy/binaries/PortableGit/versions/1.2.0/usr/bin"` |
| **沙箱拦任何显式 `bash` 调用** | 出包一律用 `node tools/build-exe.mjs` |
| **PowerShell 会吞输出** | 少用；**文件操作一律走 Python** |
| 管道里的 `tail`/`grep` 找不到 → **整条管道失败、输出被吞** | 看着像"编译静默退出"，其实是 PATH 没设 |
